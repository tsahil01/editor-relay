set it up

/install

the server starts with vs code. the status bar says Editor Relay: Running.

code --install-extension SahilTiwaskar.vscode-context-bridge

/connect

copilot picks it up on its own. for anything else, add the server with your token:

claude mcp add --transport http editor-relay \
  http://127.0.0.1:3210/mcp --header \
  "Authorization: Bearer $(cat ~/.vscode-context-bridge/token)"

/ask

"who calls this?" "rename this everywhere." "why did my last command fail?" the agent picks the tools.
