Set up in a minute

The server starts with VS Code and only listens on 127.0.0.1.

Install the extension

The status bar shows Editor Relay: Running.

code --install-extension SahilTiwaskar.vscode-context-bridge

Connect your agent

Copilot picks it up automatically. For other MCP clients, add the server with its token:

claude mcp add --transport http editor-relay \
  http://127.0.0.1:3210/mcp --header \
  "Authorization: Bearer $(cat ~/.vscode-context-bridge/token)"
