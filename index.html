Your agent asks.
VS Code answers.

Editor Relay is a VS Code extension that runs a small MCP server on your machine. Any AI agent can use it to read what you're working on, and to use the language servers, terminal, git and debugger you already have.

§1 Setup

  1. Install the extension. The server starts with VS Code, and the status bar reads Editor Relay: Running.

    code --install-extension SahilTiwaskar.vscode-context-bridge

  2. Connect your agent. Copilot finds it on its own. Other clients need the URL and your token:

    claude mcp add --transport http editor-relay \
  http://127.0.0.1:3210/mcp --header \
  "Authorization: Bearer $(cat ~/.vscode-context-bridge/token)"

  3. Ask normally: who calls this function? rename it everywhere. why did my last command fail? The agent picks the tools.

§3 Safeguards

Edits wait for you. Proposals, quick fixes and renames open as a diff with Accept and Reject. Nothing is written until you accept.

Commands wait for you. Terminal commands ask first, then run in a terminal you can see.

It stays local. The relay listens on 127.0.0.1 only and every request needs your token. Files like .env can be hidden from it entirely.
